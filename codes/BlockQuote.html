Domain Names

A domain name locates an organization or other entity on the Internet. The purpose of the Domain Name System (DNS) is to divide the Internet into logical groups and understandable names by identifying the exact address and type of the organization. The DNS associates the text-based domain names with the unique numeric IP address assigned to a device. Let's consider the domain name www.yahoo.com. The ".com" is the top-level domain name. The portion "yahoo.com" is the domain name that is registered to Yahoo! and "yahoo" is considered a second-level domain name. The "www" is the name of the web server (sometimes called web host server) at the yahoo.com domain.
